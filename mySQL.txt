- DATABASE MANAGEMENT SYSTEM -

DBMS is a software that helps us in:

1.creating databases.
2.storing data in dbs.
3.retrieve data from dbs.
4.updating data in dbs.
5.deleting data in dbs.
6.managing security.

eg: MySQL,Oracle Database,MongoDB,Microssoft SQL Server...

DBMS is of two types: SQL and NoSQL.

-------------------------------------------------------------------------

SQL

SQL stands for structured query language and it is used in relational database for CRUD operations.

RDBMS

In SQL database (relational database) the data is stored in tables, SQL queries are used for crud operations.

eg: MySQL, PostgreSQL,Oracle.

NON-RDBMS 

In non-sql databases the date is stored in formats like documents,key-value pair,.. and there is no fixed query language for crud.

eg: MongoDB, Firebase, Redis.

--------------------- SQL COMMANDS ------------------

DDL COMMANDS 

--> DDL stands for Data  Definition Language.

    1.CREATE   --> creates new databases or tables.

    2.ALTER    --> Changes table structure.

    3.TRUNCATE --> Deletes all data from table.

    4.DROP     --> Deletes databases or table.

    5.RENAME   --> Changes table name.

DML COMMANDS

--> DML stands for Data Manipulation Language.

    1.INSERT --> Adds new data.(records)  

    2.UPDATE --> Changes existing data.

    3.DELETE --> Removes data.(records)

DQL COMMANDS

--> DQL stands for Data Query Language.

    1.SELECT --> Gets data from table.

TCL COMMANDS

    1.COMMIT    --> saves changes permanently.

    2.ROLLBACK  --> undos changs.

    3.SAVEPOINT --> creates rollback point.

TRANSACTION.

    A transaction is a group of one or more SQL operations executed as a single unit.

AUTOCOMMIT.

--> Autocommit means every sql statement is saved permanently automatically.

    By default, autocommit = ON ---> This means every update,delete and insert is saved immediately.

       SELECT @@autocommit;   ---> To check autocommit status,If it is showing 1 then autocommit is on.

       SET autocommit =0;     ---> To turn off the autocommit.

       COMMIT;                ---> when autocommit is off but we want to save changes permanently.

PRIMARY KEY and FOREIGN KEY.

    Primary key ---> primary key is a column that uniquely identifies each row in a table. (Unique,not null and no duplicates.)

    Foreign key ---> foreign key is used to link to tables.

    Linking     ---> FOREIGN KEY table2(colname) REFERENCES table1(colname);

    ERRORS

    1.when try to delete a row from parent table,they wont be deleted if it is linked with any row in child table.(if it is not linked row in parent table will be deleted.)

    2.when you try to add a foreign key value in child table but if value is not present in parent table it will give a error.


    ON DELETE CASCADE   ---> if we delete row in parent table all rows linked to that row in child table will be deleted.

    ON DELETE SET NULL  ---> if we delete a row in parent table all rows linked to that row are set to null in child table.

    ON DELETE NO ACTION ---> the action will be blocked same like restrict.
    
JOINS

    Join is used to combine data from two or more tables based on a related column between them.

    INNER JOIN:

      gives only matched records in both tables.

      SELECT e.name, d.dept_name
      FROM employees e
      INNER JOIN departments d
      ON e.dept_id = d.dept_id;

    LEFT JOIN :

      returns all rows from the left table , plus matching rows from the right table.

    RIGHT JOIN :

      returns all rows from the right table,plus matching rows from the left table.


    SELF JOIN :

        SELF JOIN is a join where a table is joined with itself to relative rows within the same table.
        
        ---> use when we need relation between rows in same table.

        There is no syntax as SELF we use left join or right join to execute self join.
         USE CASES :

           Employee  ---> manager relationship.
           USER      ---> referrer relationship.
           category  ---> parent category.

    CROSS JOIN :

        retuns every possible combination of rows in both tables.

        SELECT * 
        FROM emp 
        CROSS JOIN admin;

          emp have 3 rows and admin have 4 rows cross join retuns 12 rows.

       

    UNION :

        UNION is used to combine the results of two or more SELECT queries into a single result.

        UNION returns rows without duplicates.(when we select specific column);

    UNION ALL :

        UNION ALL  combines results of two select queries and allows duplicates.
